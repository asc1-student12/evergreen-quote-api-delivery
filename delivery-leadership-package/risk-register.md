## How I'll use this register

I re-read it at the start of each working block and before each commit, because most of these fail quietly: R1, R3 and R7 all produce a response that looks fine. It is committed so the sponsor and reviewers can read it without asking. Rows that have occurred stay in, marked and dated, because Friday's review asks what actually happened. New rows get added the day they appear; Day 3's container and site work will add at least one.
